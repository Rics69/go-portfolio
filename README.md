# go-portfolio

Сайт-портфолио Данила Клементьева, Go backend-разработчика.

Next.js 16 · TypeScript · Tailwind CSS v4 · Motion. Весь текст сайта лежит в `src/content/profile.ts`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статический экспорт в out/
```
