# Портфолио Go-разработчика — дев-план

Одностраничный сайт-портфолио для откликов на вакансии Go backend-разработчика.
Задача сайта — за 10 секунд показать рекрутеру и техлиду главное преимущество:
**разработчик, который измеряет результат в цифрах** (latency, RPS, % потерь, покрытие)
и понимает весь цикл продукта (фронтенд-бэкграунд → backend на Go).

## Позиционирование

| Сильная сторона | Доказательство из опыта |
| --- | --- |
| Производительность | Переписал backend КФУ с Python/FastAPI на Go: ~250 → ~120 мс, +40% пропускной способности (pprof, benchmark) |
| Надёжность | Микросервис уведомлений на RabbitMQ: retry + dead-letter queue, потери < 1% |
| Переиспользование | gRPC-модуль авторизации для 4 проектов, −30% времени на auth |
| Качество | testify, ~70% покрытия критичных модулей |
| DX и инфраструктура | Docker / Compose: локальное окружение за ~15 минут вместо часов; миграции goose |
| Полный цикл | 3 года фронтенда (Next.js) до перехода в backend — понимаю контракт клиент ↔ API |
| Публичность | Проект представлен на технологической конференции «Технократия» |
| Масштаб | Сервис практик обслуживает тысячи студентов КФУ в пиковый сезон |

## Дизайн-направление

Основа — глобальный скилл `design-guide` (минимализм, сетка 8px, один акцент, мягкие тени)
плюс мудборд:

1. **Hero** — плавающая навигация-«пилюля», огромный центрированный заголовок
   «Данил Клементьев — Go backend-разработчик, который делает сервисы *быстрее*»,
   короткий подзаголовок в духе «4 года в разработке. 3 года на Go. Казань.»
   Вместо портрета — терминал с JSON-ответом `GET /api/v1/me` (живой эндпоинт).
2. **Преимущества** — серый фон, крупное утверждение слева + сетка из 6 пунктов с иконками.
3. **Кейсы** — большие скруглённые карточки (акцентная / белая / тёмная / серая),
   в каждой — анимированная мини-визуализация вместо картинки.
4. **Контакты** — швейцарская типографика: мета-строка сверху, огромный текст,
   строка контактов снизу.

**Токены:** белый / `#F5F5F5` / почти чёрный `#0A0A0A`, серые `#6B6B6B` и `#A0A0A0`,
единственный акцент — Gopher Blue `#00ADD8` (на белом тексте — `#007D9C` для контраста).
**Шрифты:** Onest (кириллица, заголовки и текст) + JetBrains Mono (код и мета-подписи).

**Осознанные отступления от `design-guide`** (по мудборду): крупный заголовок hero
вместо H1 32–48px, кнопки-«пилюли», радиус карточек 24px, одна карточка целиком в акцентном цвете.

## Фишки и анимации

- Заголовок появляется построчно из маски, слово «быстрее / надёжнее / понятнее» сменяется по кругу.
- Навигация со скользящей подсветкой активной секции и индикатором «открыт к предложениям».
- Счётчики метрик досчитывают при появлении в зоне видимости.
- Кейсы: гонка запросов Python vs Go, очередь RabbitMQ с retry и DLQ, gRPC auth,
  подключающийся к 4 проектам, поля JSON, подсвечивающие свою часть интерфейса.
- Опыт в виде `git log --graph`, навыки в виде `go.mod`.
- Hero-клавиатура BACK/END со звуком щелчка и поддержкой физических клавиш.
- «Связаться» везде открывает модалку с выбором Telegram или почты.
- Интерактивный терминал (`help`, `whoami`, `skills`, `sudo hire danil` …).
- Копирование email с тостом, живые часы Казани, прогресс скролла, приветствие в DevTools.
- Всё уважает `prefers-reduced-motion`.

## Стек

Next.js 16 (App Router, TypeScript, static export) · Tailwind CSS v4 · Motion ·
`next/font` · контент в одном типизированном файле `src/content/profile.ts`.
